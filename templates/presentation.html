Présentation du Projet

Contexte

Dans le cadre d'un TP universitaire de Statistiques et Analyse de Données, nous avons développé cette application pour analyser les performances des élèves de Terminale.

Le proviseur d'un lycée souhaite comprendre les facteurs influençant la réussite scolaire et prédire l'orientation la plus adaptée pour chaque élève.

Objectifs
  • Analyser la distribution des notes de mathématiques
  • Étudier la relation entre heures d'étude et performances
  • Identifier les profils d'élèves par classification non supervisée
  • Prédire l'orientation recommandée par classification supervisée
  • Produire un rapport universitaire complet exportable en PDF
Données Disponibles

Pour chaque élève, nous disposons de :

Variable Type Description Plage
note_math Continue Note de mathématiques sur 20 [4, 19]
heures_etude Continue Heures d'étude par semaine [2, 30]
orientation Catégorielle Orientation recommandée {Scientifique, Littéraire}
Technologies Utilisées
Backend
  • Python 3.11+
  • FastAPI (framework web)
  • SQLAlchemy (ORM)
  • SQLite (base de données)
Frontend
  • HTML5 / CSS3
  • Bootstrap 5 (UI responsive)
  • Plotly.js (graphiques interactifs)
Data Science
  • NumPy (calculs numériques)
  • Pandas (manipulation de données)
  • SciPy (statistiques)
  • Scikit-learn (Machine Learning)
Export
  • FPDF2 (génération PDF)
  • Rapport universitaire complet
