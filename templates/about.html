Informations sur l'application
Lycée Analytics

Application d'analyse des performances des élèves de Terminale, développée dans le cadre d'un TP universitaire de Statistiques et Analyse de Données.

Technologies
  • Python 3.11+
  • FastAPI
  • SQLAlchemy
  • SQLite
  • Bootstrap 5
  • Plotly.js
  • Jinja2
  • FPDF2

  • Pandas
  • SciPy
  • Scikit-learn
  • Matplotlib
  • Plotly

Contexte Académique

Ce projet a été conçu pour illustrer l'application des méthodes statistiques et de Machine Learning à des données scolaires réalistes.

Les analyses couvrent :

  • Statistique descriptive univariée
  • Analyse bivariée et régression linéaire
  • Classification non supervisée (K-Means)
  • Classification supervisée (Arbre de décision)
